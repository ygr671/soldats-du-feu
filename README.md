# Soldats du Feu

🇫🇷  
Soldats du Feu est une application de gestion de caserne développée en C# (.NET) avec Windows Forms.  
Le projet propose une interface permettant de gérer le personnel, les véhicules et les interventions d’une caserne de pompiers.

🇬🇧  
Soldats du Feu is a fire station management application developed in C# (.NET) using Windows Forms.  
The project provides an interface to manage staff, vehicles and interventions within a fire station.

## Présentation

🇫🇷  
L’application permet de manipuler différents éléments liés au fonctionnement d’une caserne :
- pompiers et habilitations
- véhicules et disponibilité
- interventions, type et localisation
- affectation du personnel et des véhicules

Elle a été développée en Windows Forms pour proposer une interface simple et accessible.

🇬🇧  
The application manages several aspects of a fire station:
- firefighters and their certifications
- vehicles and their availability
- interventions, their type and location
- assignment of staff and vehicles

It uses Windows Forms to provide a simple and accessible interface.

🇫🇷  
- gestion des pompiers (création, modification, suppression)  
- gestion des véhicules et de leur état  
- création et suivi des interventions  
- attribution manuelle ou semi-automatique des ressources  
- recherche et filtrage dans les listes  
- stockage des données via DataSet ou fichiers locaux (selon l’implémentation)

🇬🇧
